# **App Name**: الميراث الذكي

## Core Features:

- حساب الميراث: Ask the user to provide the details of the deceased family, including relationships and existing will or testament, then provides accurate islamic inheritance calculations with the assistance of a Large Language Model (LLM) acting as a reasoning tool to guide output.
- عرض النتائج: Display the results in a clear and well-formatted table showing each heir's share.
- تعديل البيانات: Users can manually adjust inputs and recalculate inheritance shares.
- حساب العدة: An optional feature to calculate the Iddah period for a widow based on the date of her husband's death, according to Islamic Sharia.

## Style Guidelines:

- Primary color: Sandstone (#D4A373) evoking heritage and tradition.
- Background color: Light beige (#F5F5DC) creating a soft and calming feel.
- Accent color: Olive Green (#6B8E23) to symbolize growth and prosperity.
- Use a traditional, clear Arabic font for main text and a simpler sans-serif font for UI elements.
- Clean and organized layout with clear sections for data input, results, and explanations.
- Use subtle, culturally relevant icons to represent different family members.
